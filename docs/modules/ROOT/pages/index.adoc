== Overview

Design documentation for the Cloudflare Worker that bridges Withings device data
(body composition and sleep) into Intervals.icu daily wellness records.

For setup, configuration and operational guidance, see the repository `README.md`.
The Worker implementation lives in `worker.js` at the repository root.

== Design Documents

* xref:design-sleep.adoc[Sleep Integration Design] — how Withings Sleep summaries are
  ingested and mapped to Intervals wellness fields.
* xref:design-naps.adoc[Naps Handling Design] — proposed handling of daytime naps
  (outstanding / not yet implemented).
