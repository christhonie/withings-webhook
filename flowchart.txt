IMPORTANT IMPLEMENTATION DETAILS (for reference / debugging):
 ┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
 │ - Value calculation for Withings measures: value = raw_value * 10^(unit)                                                   │
 │ - FIELD_MAPPING maps logical field names → { withingsType, intervalsField, decimals }                                      │
 │ - Use latestGrpid to identify the "canonical" group for deduplication and KV keying                                        │
 │ - Daily averages are rounded to config.decimals to avoid floating noise                                                    │
 │ - ctx.waitUntil(handler) ensures the Worker responds immediately while continuing processing asynchronously                │
 │ - Keep KV writes minimal and atomic: write sent_* only on confirmed success                                                │
 │ - Failures are recorded and kept in KV for external reprocessing instead of indefinite immediate retries                   │
 └────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
